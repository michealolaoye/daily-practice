# daily-practice

Small, real tools and exercises, built a day at a time. Mostly
dependency-light utility code, plus problem-solving write-ups and small
deploy experiments.

- `scripts/` - the tools
- `tests/` - one test file per tool
- `docs/` - one page per tool: why it exists, API, design notes
- `devlog.md` - what I worked on, newest first

Each day's work goes on a `daily/YYYY-MM-DD` branch and comes in through a
pull request. Dates in the history are the days the work was actually done.
